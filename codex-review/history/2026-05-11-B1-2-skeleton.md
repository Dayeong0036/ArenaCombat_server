## Final Code Created

### `AttackData3D.cs`
ScriptableObject in namespace `ArenaCombat.Core.Combat`. Fields:
- `attackType: AttackType` — identity
- `damageType: DamageType` — physical/etc
- `damage: float` — Min(0)
- `range: float` — distance from attacker origin to hitbox center
- `hitboxHalfExtents: Vector3` — Physics.OverlapBox half-extents (named to match API)
- `cooldown: float` — Min(0)
- `appliedStatus: StatusMask` — defaults to None; B1-4 will only honor None until status duration model exists

`[CreateAssetMenu(fileName = "AttackData3D_New", menuName = "ArenaCombat/Combat/AttackData3D", order = 100)]` — assets created via `Assets > Create > ArenaCombat > Combat > AttackData3D`.

### `CombatManager3D.cs`
NetworkBehaviour singleton in namespace `ArenaCombat.Core.Network`. `[RequireComponent(typeof(NetworkObject))]`.

Lifecycle:
- `Awake()` — singleton check, Destroy if duplicate
- `OnNetworkSpawn()` — server-only: `BuildAttackLookup()` + log
- `OnNetworkDespawn()` — clear Instance, players3D, attackLookup

Public API:
- `RegisterPlayer3D(ulong, PlayerNetworkController3D)` — server-only, null-guarded, logs
- `UnregisterPlayer3D(ulong)` — server-only, logs on remove
- `GetPlayer3D(ulong) → PlayerNetworkController3D` — TryGetValue lookup
- `Lookup(AttackType) → AttackData3D` — lazy-built attack table lookup; returns null when not configured (caller responsibility)

State:
- `players3D: Dictionary<ulong, PlayerNetworkController3D>` (server-only)
- `attackTable: List<AttackData3D>` (Inspector-assigned)
- `attackLookup: Dictionary<AttackType, AttackData3D>` (lazy cache, rebuilt on first Lookup after spawn)

What's NOT here (deferred to later sub-items):
- Resolver methods (`TryProcessAttack3D` / `TryProcessParry3D`) — B1-3 stubs / B1-4 full
- Result RPCs — B1-3
- K/D/A dicts — B1-5
- Caller wiring (no one calls `RegisterPlayer3D` yet) — B1-3
