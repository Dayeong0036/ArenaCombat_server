## Lessons

- **Mojibake-broken strings will not even compile**: X2-12 Codex caught `"[CardManager] ?щ’ 媛??李?` unclosed quote. Same lesson as X2-10 SkillLibrary attached-comment-method-decl. **All future Buildup imports: assume verbatim copy will fail compile; reconstruct from semantic intent.**
- **Header warnings for legacy patterns are MANDATORY**: X3 wiring engineer (likely future-me) needs to see `Time.timeScale = 0f` warning before adding CardManager to a production scene. Codex insisted on explicit "DO NOT activate before X3 wiring replaces..." block.
- **PlayerSkillSlot intentional omission held through X2 close**: SKILL_SYSTEM_DESIGN.md auto-cast only model meant we skipped one Buildup file (PlayerSkillSlot.cs, ~100 LOC). M-1 branch removal in CardManager preserves that decision. **Design intent flowed cleanly through 8 dependent rounds without resurrection of the dead concept.**
- **PHASE X2 = 12 successful Codex rounds, 1 workflow violation**: workflow rule held since X2-7. The strict gate (pending → Codex → apply) caught 4 critical Buildup origin bugs that verbatim policy would have shipped. ML preservation policy + clean rewrite + namespace discipline scaled to ~5,900 LOC across 32+ files.
